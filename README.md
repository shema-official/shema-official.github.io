# 찬양팀 연습 참여 조사

- `index.html`: 멤버 응답 페이지 (로그인 없이 이름 선택)
- `admin.html`: 관리자 페이지 (조사 열기/마감, 수정 요청 승인, 일정·멤버 관리, 표 생성·PNG 저장)
- `Code.gs`: 구글 시트에 붙는 Apps Script API
- `common.js`: 두 페이지 공용 (API 주소, Tailwind 설정, 공통 스타일)
- `sheet.js`: 연습표와 멤버 캐릭터·색상 (두 페이지 공용)

## 월별 운영 흐름
1. 관리자: 월 선택 → **토요일 자동 추가** → 연습 없는 주 체크, 추가 연습 입력 → **일정 저장**
2. 관리자: **조사 열기** → 멤버들에게 `index.html` 링크 공유
3. 멤버: 이름 선택 → 연습마다 참석/불참(불참이면 사유 + 주일 예배 참석 가능 여부) → 저장
4. 관리자: 미응답자 확인 → **조사 마감하기**
5. 마감 후 멤버가 응답을 바꾸면 **수정 요청**으로 들어오고, 관리자가 승인해야 반영됩니다.
6. 관리자: 참석 현황표 / 불참자 정리표 → **PNG 저장** → 단톡방 공유

## 처음 설정 (한 번만)
1. 구글 시트를 새로 만듭니다. 탭은 만들지 않아도 됩니다(처음 호출 때 자동 생성).
2. https://script.google.com/create 에서 새 프로젝트를 만들고 `Code.gs` 내용을 통째로 붙여 넣습니다. `SHEET_ID`는 시트 URL의 `/d/`와 `/edit` 사이 값으로 바꾸고 저장합니다.
3. Apps Script 왼쪽 **프로젝트 설정 → 스크립트 속성 추가**: 속성 `ADMIN_PW`, 값은 관리자 비밀번호.
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 `https://script.google.com/macros/s/.../exec` URL을 복사합니다.
5. `common.js`의 `API` 값을 그 URL로 바꿉니다.
6. GitHub에 새 공개 저장소를 만들어 이 폴더 파일을 올리고, **Settings → Pages → Branch: main / root**로 켭니다.
   - 멤버용: `https://<아이디>.github.io/<저장소>/`
   - 관리자용: `https://<아이디>.github.io/<저장소>/admin.html`

`Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다(URL은 그대로 유지).

## 알아둘 점
- 이름 선택 방식이라 다른 사람 이름으로 응답하는 것을 막지 못합니다.
- 멤버 이름을 바꾸면 이전 응답과 연결이 끊어집니다. 이름은 가능하면 고정해서 쓰세요.
- 데이터는 구글 시트에 그대로 남으므로, 시트에서 직접 보거나 고칠 수 있습니다.
